WinOps_Toolkit

Double-click WinOps_Toolkit.cmd. It automatically requests Administrator privileges.

Designed for authorized Desktop Support / Network Support troubleshooting.

Includes:
- DISM / SFC / CHKDSK
- DNS flush, DHCP renew, Winsock/TCP-IP reset
- Ping, DNS, tracert, routes, netstat, WLAN report
- CPU/RAM/BIOS/GPU/disk/network/battery information
- Disk and volume checks
- BitLocker status, protector status, suspend/enable, and confirmed full decryption
- Users, administrators, services, installed software, startup programs
- Event logs, Reliability Monitor, system information
- Device Manager, Disk Management, Services, Event Viewer, Task Manager
- Defender and firewall status
- Restart/shutdown controls

Important: BitLocker full decryption is destructive to the protection state and requires typing DECRYPT.
DiskPart can make destructive disk changes. Use only when you understand the command and have authorization.
